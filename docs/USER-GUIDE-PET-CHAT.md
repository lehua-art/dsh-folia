# 桌宠对话功能 · 使用指南（4.26.0 预览版）

> 这一版让桌宠"能和你聊天、记得你的偏好、偶尔主动搭话、还能听你说话"。
> 聊天用的是**你自己的 AI 模型**（DeepSeek 或本机 Ollama），插件本身不收费、不收集你的对话。

---

## 一、安装与升级

```
1. 打开 DSH → 插件管理 → 找到 Folia（dsh-folia）
2. 更新通道切到 **next**（预览通道），安装 4.26.0-pre.1
   · 稳定版仍是 4.25.5，想回退随时切回 latest
3. 装完重启 DSH
```

---

## 二、第一次配置（只需一次）

### 2.1 填自己的模型 Key（推荐 DeepSeek）

```
插件 → 设置 → 桌宠 → 桌宠对话
  provider : openai
  baseUrl  : https://api.deepseek.com
  model    : deepseek-chat
  apiKey   : 你的 sk-...（只存你自己电脑，不上传）
  enabled  : 打开
保存
```

```
费用：按你自己的 DeepSeek 额度计费，一次对话几分钱都不到
（不想花钱：装 Ollama 后选 provider=ollama，完全离线免费）
```

### 2.2 人设（可改）

```
名字：Folia（默认）
性格：元气、有点粘手、不说教（默认）
口吻：短句、偶尔颜文字（默认）
```

## 三、怎么用

| 想做的事 | 操作 |
|---|---|
| 聊天 | **点一下桌宠** → 弹出气泡 → 打字 → Enter 发送（Esc 关闭） |
| 快捷唤起/隐藏 | `Ctrl + Alt + P` |
| 让它记住偏好 | 直接说"记住我喜欢原神""记住我叫你小F" |
| 看它记住了什么 | 设置 → 桌宠对话 → 「查看记忆」 |
| 清空记忆 | 气泡右上角「清空记忆」或设置里的清空 |
| 关掉 AI（只留预设台词，0 成本） | 设置里关掉 enabled |
| 主动闲聊 | 设置里打开（**默认关**）；打开后会显示"今日已说 N/10" |
| 不让它今天说话 | 点「今天别说了」，次日自动恢复 |
| 语音输入（按住说话） | 见下方 3.2 |

### 3.1 主动闲聊的限制（避免打扰）

```
· 每日最多 10 条，两次间隔 ≥2 小时
· 22:00–08:00 静默
· 只在你空闲 ≥10 分钟、且不在全屏时才会说话
· 随时可以"今天别说了"
```

### 3.2 语音输入（需要先开启系统语音能力）

```
第一次使用前：
  DSH 设置 → 开启"语音输入" → 会下载约 228MB 中文语音模型（只下一次）
使用：
  点桌宠 → 按住麦克风按钮说话 → 松开 → 识别结果出现在输入框
  · 不会自动发送，确认后再按 Enter
  · 语音不可用时会提示，可继续打字
```

### 3.3 朗读回答（下一版推出）

```
计划：桌宠把回答念出来（默认开），可选"系统音色"或"在线情感音色"（按情绪变调）
当前预览版：只有文字气泡，还没有朗读
```

## 四、常见问题

**Q：为什么点了桌宠没反应？**
A：先检查 设置 → 桌宠对话 → enabled 是否打开、key 是否填了。气泡上方会显示"已连接 · openai · deepseek-chat"或具体错误。

**Q：提示 401 / unauthorized？**
A：key 填错或已失效，重新粘贴一次。

**Q：提示"连不上模型端点"？**
A：网络问题，或 baseUrl 写错（DeepSeek 是 `https://api.deepseek.com`，不要带 `/v1`）。

**Q：语音输入提示 asr-not-ready？**
A：还没在 DSH 里开启语音输入（模型未下载），按 3.2 开启一次即可。

**Q：它会自己说话吗？**
A：只有你打开"主动闲聊"才会，且有每日上限与静默时段。

**Q：会花我很多钱吗？**
A：你正常聊天，几十次也就几分钱；它自己主动说话也受上限限制；关掉 AI 后完全 0 成本。

**Q：怎么回退到稳定版？**
A：插件管理里把通道切回 latest（4.25.5），或重装 4.25.5。

## 五、隐私

```
· 对话内容只发给你自己配置的模型端点（DeepSeek 或本机 Ollama）
· 记忆只存在你本机（~/.dsh-folia/pet-chat/memory.json），可查看、可清空
· 插件不收集、不上传你的对话；我们看不到你的 key
```
