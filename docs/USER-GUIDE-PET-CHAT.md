# 桌宠对话 · 测试手册（4.26.0-pre.1 预览版）

> 给测试用户：按顺序做完 T0–T13，每条记录"通过/不通过 + 现象"。
> 不通过就截图 + 复制气泡里的错误文字，发回给我们。

---

## 0. 准备

```
需要：
① 已安装 DSH Desktop（Windows）
② 一个自己的模型凭据（二选一）：
   a. DeepSeek API Key（platform.deepseek.com 注册，充值几元即可）
   b. 本机 Ollama（免费，需先安装并 ollama pull qwen2.5:7b）
③ 可选：想测语音输入，需要在 DSH 设置里开启"语音输入"（会下载约 228MB 模型）
```

---

## 1. 安装（T0）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T0-1 | DSH → 插件管理 → Folia → 更新通道切 **next** → 安装/更新 | 显示 4.26.0-pre.1 |
| T0-2 | 重启 DSH | 插件正常加载，壁纸功能不受影响 |
| T0-3 | 打开插件 → 桌宠页签 | 能看到桌宠（如鲸鱼娘），能正常显示/拖动 |

**不通过现象**：装完是 4.25.5、插件报错、壁纸功能坏了 → 立刻截图回报，并切回 latest。

---

## 2. 配置模型（T1）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T1-1 | 设置 → 桌宠 → 桌宠对话 | 看到 provider/baseUrl/model/apiKey/enabled |
| T1-2 | 填：provider=openai，baseUrl=`https://api.deepseek.com`，model=`deepseek-chat`，apiKey=你的 key | 能保存 |
| T1-3 | 打开 enabled | 气泡顶部显示"已连接 · openai · deepseek-chat" |

**不通过现象**：显示"连不上模型端点"（检查网络/baseUrl）、"未开启对话"（检查 enabled）。

---

## 3. 对话（T2–T4）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T2 | 点一下桌宠 | 弹出气泡，有输入框 |
| T3 | 输入"你好，你是谁？"，Enter | 1–2 秒内开始逐字显示回答，不是整段蹦出 |
| T4-1 | 连续问 5 轮（如"你记得我上一句问什么吗"） | 记得上一句；语气保持"元气、短句" |
| T4-2 | 问一句明显超纲的（"帮我写代码"） | 它会委婉拒绝/简短回应，不会变成通用助手 |

**记录**：首字延迟大概多少秒（感觉即可）。

---

## 4. 记忆（T5–T6）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T5-1 | 说"记住我喜欢原神，叫我小F" | 回复确认 |
| T5-2 | 设置 → 查看记忆 | 能看到 nickname/喜欢/备注 |
| T5-3 | 关掉 DSH 再打开 → 问"我喜欢什么" | 能说出"原神" |
| T6 | 点"清空记忆" → 再问 | 表示不知道；查看记忆为空 |

---

## 5. 关闭 AI / 错误处理（T7–T8）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T7 | 设置里关掉 enabled → 点宠物说话 | 回预设台词，无网络请求，0 成本 |
| T8-1 | 把 apiKey 清空 → 打开 enabled → 发消息 | 提示"没有配置模型"，并回一句预设台词（不能卡死/白屏） |
| T8-2 | 把 baseUrl 改成一个错的地址 → 发消息 | 提示连接失败，并给重试；不崩溃 |

---

## 6. 主动闲聊（T9–T10，可选）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T9-1 | 设置里打开"主动闲聊" | 看到"今日已说 0/10" |
| T9-2 | 把窗口放着不动 10–15 分钟（别全屏） | 若触发，气泡出现一句 ≤40 字的话，计数变 1 |
| T9-3 | 连续观察 2 小时 | 两次间隔 ≥2 小时，不会刷屏 |
| T10 | 点"今天别说了" | 当天不再主动说话 |

**注意**：默认是关的；开启后才会说话。

## 7. 语音输入（T11，需要先开 DSH 语音）

| 步骤 | 操作 | 预期 |
|---|---|---|
| T11-0 | DSH 设置 → 语音输入 → 开启，等模型下载完（约 228MB） | 显示可用 |
| T11-1 | 点桌宠 → 按住麦克风 → 说"你好" → 松开 | 输入框出现"你好" |

| T11-3 | 不开 DSH 语音直接按麦克风 | 提示"语音不可用"，不崩溃，可继续打字 |

## 常见问题

**Q：点了宠物没反应？** → 检查 enabled、key；气泡上方有状态提示。

**Q：401？** → key 错/失效，重新粘贴。

**Q：连不上端点？** → baseUrl 必须是 `https://api.deepseek.com`（不要 `/v1`、不要尾斜杠）。

**Q：语音提示 asr-not-ready？** → 还没在 DSH 开语音输入（模型没下载）。

**Q：它会自己说话吗？** → 只有开启"主动闲聊"才会，且有每日上限与静默时段。

**Q：花钱吗？** → 花你自己 key 的钱（几十次几分钱）；关掉 AI 后 0 成本。

**Q：怎么回退？** → 插件通道切 latest（4.25.5）。
