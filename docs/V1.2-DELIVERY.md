## 2. 设置项（`settings.petChat` 新增）

```jsonc
{
  "conversationMode": "chat",       // chat | story | treehole | observe
  "voiceLength": 8,                 // 0=不限 | 3 | 8（默认 8；旧版写死 3）
  "proactive": { "enabled": false, "intervalMin": 15, "quietFrom": "23:00", "quietTo": "08:00" },
  "screen":    { "mode": "off", "confirmed": false },   // off | app | ocr
```

## 3. 迁移说明：JSONL → SQLite

### 3.1 落点

```
<DSH_FOLIA_HOME or ~/.dsh-folia>/personas/<personaId>/memory/
    events.jsonl      # 旧事件流（迁移后保留，只读备份）
    summary.json      # 旧摘要（迁移后保留）
    archive/*.jsonl   # 旧归档（迁移时一并读入）
    memory.db         # 新库（WAL）
```

### 3.2 字段映射

| JSONL | events 表 | 说明 |
|---|---|---|
| `id` (`e_…`) | `id` (INTEGER) | 旧 id 不保留；DB 用自增 rowid，接口对外仍以字符串回 |
| `ts` | `created_at` / `last_used_at` | 同值写入（迁移时按原时间，不打乱新旧） |
| `kind` | `kind` | 新增 `observation` / `treehole`；旧值原样 |
| `text` | `text` | 原样（≤4000 字） |
| `importance` | `importance` | 1–10，原样 |
| `refs[]` | `tags` | 逗号串；读回时 `refs` 为空数组（兼容旧形状） |
| （无） | `pinned` | `kind=preference` 默认 pinned；迁移不额外改判 |
| （无） | `strength` | `importance × 3`（天）作为衰减时间尺度 |
| （无） | `source` | 迁移写入 `jsonl-migration` |
| `summary.json.text` | `summaries(period='latest')` | 迁移时导入一次 |
| （无） | `meta.jsonl_migrated_at` | 迁移标记；幂等（已迁移则 `imported=0`） |

### 3.3 索引与检索

- `events_fts` / `lore_fts` 是 **FTS5 `content='' contentless_delete=1`**，存的是
  **预分词后的索引串**（中文 bigram + 英文/数字词 + 单字）。原生 `unicode61` 把连续中文当
  一个 token，`咖啡` 查不到 `我喜欢喝咖啡` —— 所以两边（入库/查询）都走 `tokenizeForIndex()`。
- 检索：FTS5 `bm25` 相对归一 + recency（半衰期 30 天）+ importance + retention（`exp(-days/strength)`）+
  JS 字符 n-gram 余弦（0.05 权重，**不是 ONNX 向量**；有 embedder 时才写 `embedding` 列）。
- 候选池是 **FTS top-60 ∪ 最近 60 ∪ pinned ≤30**：只取 FTS 会让“刚记住的偏好”在下一句
  无关提问时被挤掉（实测缺陷，见 `verify-pet-chat` B①）。
- 衰减：`retention < 0.05` 且 importance < 8 → `archived=1`（**归档不删**）；pinned 永不衰减；
  命中一次 `strength + 1`。

### 3.4 回退开关

- `FOLIA_MEMORY_DB=0`（或 `off`）：整个进程回到旧 JSONL 路径，行为与 1.1.0 一致；
- `node:sqlite` 不可用 / 打开失败 / 迁移失败：该人设**按人设**回退 JSONL（`memoryBackend(id)==='jsonl'`），
  不影响另外的人设，也不阻塞聊天；
- 迁移幂等：`meta.jsonl_migrated_at` 已存在则跳过；JSONL 永不删除。

### 3.5 新 HTTP 端点（`/folia/pet-chat/personas/<id>/…`）

```
GET    memory/stats          # 统计 + 后端 + 迁移信息 + 库路径
GET    memory/export         # JSON 附件（events/relations/lore/summaries）
POST   memory/decay          # 手动跑一次衰减 tick
POST   memory/rollback       # { before } 或 { date }
DELETE memory/by-date?date=  # 按日期回滚
GET    observations          # 观察记录
DELETE observations          # 清空观察
DELETE observations/<id>     # 删除单条观察
GET/POST relations           # 关系/好感度（-10..10）
DELETE relations/<entity>
GET/POST lore                # 世界书（500–800 字分块；导入文档时自动写入）
DELETE lore/<id>
```

## 4. 隐私说明（屏幕感知 / 观察 / 主动）

- **默认全关**：`screen.mode=off` 时连 PowerShell 都不会起（`observeOnce` 在调用
  `readForegroundWindow` 之前 return）；`proactive.enabled=false` 时 `/mind/tick` 直接 `disabled`。
- Level 1 只读 **前台应用名 + 窗口标题摘要**（≤120 字），30–60 秒一次。
- Level 2 截屏只进 **内存**（`System.Drawing` → `MemoryStream` → `InMemoryRandomAccessStream` →
  `Windows.Media.Ocr`），**不写临时文件、不落盘、不上传、不进日志**；OCR 文本只写本机记忆。
- 按进程名/标题跳过密码管理器、银行/支付、远程桌面；锁屏/LogonUI 直接停。
- 所有观察写入 `memory.db` 的 `events`（`kind=observation`，importance 2–3），
  设置页可查看 / 单条删除 / 清空；删除人设会连同记忆目录一起删。
- 树洞危机词只在本地判定；安全提示里的热线可配置，不内置任何医疗/法律建议。

## 6. 已知限制（不藏）

1. **中文分词是 bigram 预分词**，不是原生中文分词/向量检索；同义改写（“好喝” vs “美味”）
   只能靠 n-gram 余弦小幅补偿，不保证召回。
2. **OCR 质量受系统语言包与画面影响**：小字、深色主题、游戏/视频画面会漏字或空格化；
   没装中文 OCR 语言包时 `TryCreateFromUserProfileLanguages` 可能返回空 → 如实回 `no-ocr-engine`，不假装看到。
3. **OCR 只截主屏虚拟桌面**（`VirtualScreen`），多显示器拼图分辨率过高时识别更慢；
   目前没有逐显示器选择。
4. **故事长度仍受模型端点上限约束**：`num_predict=6000` 只是放宽请求；
   端点自身截断（如 4096 token）时故事会提前结束，客户端无法补全。
5. **故事 TTS 是 2 句一批**（≤240 字/请求），不是语义分段；超长段落仍按标点/字数硬切。
6. **主动思维目前由客户端 5 分钟轮询 `/mind/tick` 驱动**（桌面宠物在线时才触发）；
   没有“宿主独立后台定时器”——这是有意的：不额外驻留后台进程。
7. **关系抽取是保守正则**（喜欢/讨厌/在做/叫我），不会做实体消歧；“星穹铁道”和“星铁”
   会当成两个实体。
8. **世界书 RAG 只在导入文档/角色卡时写入 lore**；手工改 `persona.core.worldBook` 仍走
   旧的整段匹配（keyword），不会自动同步进 lore 索引。
9. **`node:sqlite` 仍是 Node 实验特性**：运行时会打印 `ExperimentalWarning`（不影响功能）；
   未来 Node 改 API 时可能需要在 `memory-db.js` 一处适配。
10. **4 个系统音效是合成提示音**，不是角色语音；没有内置任何角色/声优素材，
    需要角色音色必须由用户导入并自担授权（界面已强制 license/作者提示）。
11. **调试/诊断**：`/observe/sample` 可强制采一次（含 OCR），仅供排障；界面不暴露该按钮。
12. **审计脚本改动**：`test/run-audit.mjs` 的子进程输出改走临时文件（Windows 上浏览器测试
    会让管道 EOF 永远不到，整套 audit 挂死）。判据语义未变。
