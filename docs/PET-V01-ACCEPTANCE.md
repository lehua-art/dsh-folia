# v0.1 验收清单（桌宠语音助手：语音输入 + 头顶文字气泡）

> 范围：v0.1 = 语音输入（STT）+ 头顶文字气泡 + 名字/记忆 + 主动搭话（零配置）。
> **不含任何朗读/TTS**（v0.2 再做）。
> 验收分三方：A 机自检 → B 机（主机器，有 DSH + 麦克风）真机验收 → 用户体验验收。

---

## 0. 分工

| 谁 | 做什么 | 能不能替代 |
|---|---|---|
| **A 机**（无 DSH） | 门禁 + 单测 + 静态判据 + 提交报告 | 不能做真机 |
| **B 机**（我们） | 安装、重启、点桌宠、说话、看气泡、计时主动搭话、语音叫停 | 唯一能做 |
| **用户（你）** | 体验判断：气泡位置/文字是否舒服/是否太吵 | 最终拍板 |

---

## 2. B 机真机验收（我这边执行）

### 前置（用户先做，5 分钟）
```
P1 重填 DeepSeek key（现有 key 报 401 unauthorized）
P2 开启 DSH 语音输入并等 228MB 模型下载完成（否则 STT 一直 asr-not-ready）
```

### T1 安装与启动
```
步骤：插件通道 latest → 安装 pre.8 → 重启 DSH
预期：能进界面；harness.log 无 "dsh-folia" 失败记录
证据：插件版本 / 日志片段
```

### T2 头顶气泡（核心）
```
步骤：点一下桌宠
预期：桌宠**头顶**出现气泡（不是聊天窗口），里面是短提示（如"嗯？"）
步骤：再点一下；然后再点第三下
预期：关闭 → **能再次打开**（这次必须成立，旧版就是关掉打不开）
证据：截图
```

### T3 打字（兜底入口）
```
步骤：右键桌宠 → 打字说 → 输入"你好，你是谁" → 回车
预期：气泡逐字显示回答；**没有声音**（v0.1 不朗读）
```

### T4 语音输入（核心）
```
步骤：点桌宠 → 看到"正在听…"→ 说"你好，帮我看看今天天气" → 停顿 1.5 秒
预期：① 气泡显示转录文本 ② 随后显示回答（逐字）③ 全程无声音
失败分支：麦克风拒绝权限 → 给提示 + 自动退回打字
```

### T5 名字与记忆
```
步骤：说"记住我叫你小F，我是主人"
预期：确认回复
步骤：重启 DSH → 点桌宠问"我叫你什么？"
预期：答"小F"；再问"我是谁"→ 答"主人"
证据：右侧记忆文件内容（~/.dsh-folia/pet-chat/memory.json）
```

### T6 记忆管理
```
步骤：右键 → 记忆
预期：显示昵称/偏好；有清空按钮
步骤：清空 → 再问"我叫你什么"
预期：不再知道（且不报错）
```

### T7 主动搭话（周期性）
```
步骤：开启测试快进开关（A 机需实现：过程变量 FOLIA_PET_PROACTIVE_FAST=1，把 40–90 分钟压到 60–90 秒）
预期：放着不动 → 每 60–90 秒最多一句，≤30 字，内容相关（时间/壁纸/记忆）
证据：3 条搭话内容 + 时间戳
```

### T8 语音叫停 / 恢复
```
步骤：点桌宠 → 说"别说了"
预期：气泡回"好，那我安静一会儿"；之后 5 分钟内不再主动搭话
步骤：点桌宠 → 说"可以说话了"
预期：恢复主动搭话
步骤：不点桌宠，等 2 分钟
预期：验证"静默期间主动搭话确实停止"（tap 唤醒本身不算主动搭话）
```

### T9 失败与降级
```
T9-1 清空 key → 点桌宠说话 → 预期：气泡提示"未配置模型"+ 一句预设台词，不崩
T9-2 把 baseUrl 改错 → 预期：提示连接失败 + 可重试
T9-3 不开 DSH 语音输入 → 按麦克风 → 预期：提示"语音不可用"，可继续打字
```

### T10 设置页极简
```
步骤：打开设置
预期：只有 3 项（Key / 名字 / 音色占位）；**没有**开关、没有静音按钮、没有频率设置
```

### T11 回滚
```
步骤：通道切 latest（4.25.5）→ 安装 → 重启
预期：壁纸/皮肤/桌宠一切正常；再切回 pre.8 也正常
```

## 3. 用户体验验收（你）

```
U1 气泡位置：是否在桌宠头顶、跟随拖动、不挡视线
U2 文字节奏：逐字速度是否舒服、超长是否换行合理
U3 主动搭话：频率是否合适（太吵/太安静），内容是否自然
U4 语音识别：说出的话能否被正确转录（常用语 3 句）
U5 总体：是否愿意日常开着它
```

## 4. 通过标准

```
必过：T1–T6、T9、T10、T11
可接受偏差：T7 频率需微调（记下限值，下一版调整）；T8 恢复需点一下桌宠（已知限制）
一票否决：气泡关掉打不开 / 插件导致 DSH 启动失败 / 语音输入崩溃
```

## 5. 失败处理

```
· 任何一条失败：记录现象 + 截图 + 日志片段 → 退回 A 机修 → 重新发 pre.N+1
· 出现"启动失败/崩溃"：立即把 latest 指回 4.25.5（回滚 30 秒）
· 频率/文案类问题：不阻塞发布，记进下一版
```
