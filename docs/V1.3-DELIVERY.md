# dsh-folia v1.3.0 交付说明（意图优先）

- 基线：`1.2.0`
- 目标/实际版本：`1.3.0`（`package.json` + `package-lock.json`）
- 分支：`feat/machine-a-intent-first`
- 未 npm publish（版本号由主对话统一发布）

本版按**用户流程**改：不再有“模式”可切，讲故事/共情由**当轮文本**自动判定；
`conversationMode` 只保留字段兼容，运行时恒为 `auto`。

---

## 1. 改了什么

### 1.1 「对话与隐私」入口（U1–U4）

- `src/panel-tabs-assistant.js`
  - `AssistantSection` 第一屏：标题右侧新增
    **`⚙ 对话与隐私 / 朗读 / 工作能力`** 按钮（`id=we-assistant-settings-entry`）；
  - 点击后在**当前页**展开 `PetChatSettings`，默认 `behavior`；再点「收起设置」折叠；
  - 展开区顶部四个页签：对话与隐私 / 助手 / 朗读与音色 / 工作能力；
  - 四个页签共用 `draft` 状态（切页不丢草稿）；
  - `function PetChatSettings()` **签名未改**（构建 marker 原样保留），
    初始页签通过 `React.createElement(PetChatSettings, { initialTab })` + `arguments[0]` 读取。
- 构建：`scripts/build-client.mjs` 的 marker 未改动；U4 由真构建验证。

### 1.2 删除“模式”（S6）

- 设置页删除「对话模式」下拉（聊天/讲故事/树洞/只观察）；
- 右键菜单删除「模式」分组（`we-pet-mode` 事件、`modeHead` 全部移除）；
- 客户端删除 `petChatConversationMode / petChatSetMode / getMode / setMode`；
- `settings.petChat.conversationMode` 字段保留（旧包兼容），`readPetChat` 一律回落 `'auto'`，
  宿主 `handleConfigPost` 不再接受模式写入。

### 1.3 意图自动识别（S1–S5、S7）

`lib/pet-chat-brain.js`：

```js
resolveTurnPolicy(text, { lastWasStory }) → { policy: 'chat'|'story'|'empathy', reason, storyContinue }
```

| 用户说 | policy | 行为 |
|---|---|---|
| 讲个故事 / 讲长一点 / 编个童话 / 详细讲 / 展开讲 / 给我讲个… | story | prompt 800–1500 字、开头/发展/结尾、不列 Markdown；`num_predict=6000`；不按 3/8 句截断；TTS 2 句/批；气泡保留；本轮显示「继续讲/重讲/缩短」 |
| 继续讲 / 接着讲 / 后来呢 / 然后呢（上一轮是故事） | story | 把上一段结尾（内存 ≤3000 字）注入 prompt，接着写 |
| 今天好累 / 烦 / 难受 / 压力…（无明确任务/求建议） | empathy | 先接住情绪 + 一个开放问题；不列 1/2/3、不诊断；危机词走固定安全回应 |
| 帮我查天气 / 好累怎么办 / 讲个笑话 / 讲一下这个代码 | chat | 正常 chat / tool / 教学 |

- 判定只影响**本轮**：下一轮自动回到 chat，不持久化、不落盘、不需要任何开关；
- 故事按钮只在 `petChatTurnPolicy==='story'` 时出现，下一轮开始即隐藏；
- 客户端从 `meta.policy` / `done.policy` 读取本轮策略，TTS、气泡、按钮都跟着这一轮走。

### 1.4 静音（S4）

- `别说话了 / 别说话 / 安静 / 闭嘴 / 别吵 / 不要说话了` → `voice.muted=true`（字幕继续），
  响应 `done.muted=true`；客户端立刻停 TTS 并置「🔇 仅文字」；
- `可以说了 / 可以说话了 / 说话吧` → `muted=false` 恢复；
- **不改任何对话策略**，也不写 `conversationMode`。

### 1.5 只观察（隐私）

- 不再是对话模式：**屏幕感知开启 + 主动搭话关闭** 时，状态条显示「👁 观察中」；
- 聊天不再有 observe 分支（不会因为“模式”拒答）；
- 观察记录仍由 `lib/desktop-context.js` 采样写入（kind=observation，2–3），可查/删/清空。

## 4. 已知限制

1. 意图判定是**规则/正则**，不是模型分类器；过分离谱的说法可能落回 chat（可接受，不会误删能力）。
2. “继续讲”依赖宿主进程内上一段故事；**重启/换人设后**再从“后来呢”开始会当新故事。
3. 故事长度仍是“请求上限”，模型端点自身截断时无法补全；`num_predict=6000` 只是放宽请求。
4. 静音是**持久设置**（写 `voice.muted`），不是只静音当前一句；“可以说了”恢复。
5. 只观察 = 屏幕感知开 + 主动搭话关；**不会**因为“只观察”而拒绝聊天（没有这个模式了）。
6. 危机词仍是本地关键词规则，覆盖常见自伤表达，不保证覆盖所有隐晦说法。
7. 设置页展开区是页内面板，不是新一级导航；四个页签在 `PetChatSettings` 内部切换，
   **共用同一份草稿**（不重挂载，不丢未保存内容）；收起再展开会回到默认「对话与隐私」页签。
8. `conversationMode` 字段仍在设置文件里（恒 `auto`），删除字段会破坏旧包兼容，暂不清理。
